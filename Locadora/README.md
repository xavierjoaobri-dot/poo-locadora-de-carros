# poo-locadora-de-carros

## Dupla
João Otavio e Laura Boscardin

## Problema escolhido

 
Uma locadora precisa controlar clientes, veículos e locações. Cada locação associa um cliente a um veículo. Um veículo possui placa, modelo e disponibilidade. Ao realizar uma locação, o veículo fica indisponível. Ao finalizar a locação, o veículo volta a ficar disponível. Uma locação finalizada não pode ser finalizada novamente.
 
## Classes principais

 

- Classe 1: Main

- Classe 2: Veículo

- Classe 3: Cliente

- Classe 4: Locação

 

## Relações entre classes

 A Main anota veículos e clientes. Veíiculo mostra modelo, disponivel e placa. Locação mostra cliente, veiculo, dataLocacao e dataDevolucao e Clientes mostra o nome, cpf e email.

## Como executar

 

```bash

javac Main.java

java Main

```
